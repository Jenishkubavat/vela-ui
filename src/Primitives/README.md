# Vela.UI.Primitives

Unstyled building blocks for accessible Blazor components. A primitive
handles behavior only: focus management, keyboard navigation, ARIA
attributes, and open/close state. It renders no CSS classes, so you can
style it with Tailwind, plain CSS, or anything else.

[Vela UI](https://github.com/Jenishkubavat/vela-ui) components are built
on these primitives, in the way shadcn/ui is built on Radix.

This package is empty for now. The first primitives arrive with Vela UI's
Dialog component.
